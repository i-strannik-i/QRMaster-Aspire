QRМастер Aspire 1.1.0

QRМастер Aspire

Гаджет для Vectric Aspire 12.5, Windows x64. Вставьте ссылку и укажите диаметр фрезы — гаджет создаст замкнутые квадратные векторы QR-кода.

Версия: 1.1.0. Единственный режим — квадратики под карман Pocket.

#Скачать и установить

1. Откройте [последний релиз](https://github.com/i-strannik-i/QRMaster-Aspire/releases/latest).
2. Скачайте QRMaster_Aspire_1.1.0.vgadget из Assets.
3. В Aspire выберите Gadgets → Install New Gadget… и укажите файл.
4. Создайте или откройте проект, затем запустите Gadgets → QRMaster Aspire.

Python отдельно устанавливать не нужно: движок входит в пакет. Если пункт меню не появился после установки, перезапустите Aspire.

#Использование

В мастере всего два поля: ссылка и диаметр фрезы в миллиметрах. Нажмите «Создать QR». После успешного создания мастер закрывается; векторы остаются выделенными на слое QR_SQUARES.

Размер рассчитывается автоматически из числа элементов QR и диаметра фрезы. Минимальный шаг элемента — 110% диаметра фрезы; общий размер округляется вверх до 0,01 мм. При фрезе 4 мм и ссылке https://example.com получается QR 162,81 × 162,81 мм с защитным полем. Более длинная ссылка может потребовать большего размера.

QR располагается у левого нижнего угла листа, с пустым полем шириной четыре элемента со всех сторон. Ввод размеров и выбор отступов не нужны. Существующая геометрия сохраняется: повторное создание добавляет новый QR.

Назначьте выделенным векторам Pocket, выберите фрезу того же диаметра, который указали в мастере, и задайте глубину обработки. Гаджет создаёт векторы; рабочие траектории, подачу, обороты и глубину вы задаёте в Aspire. В дюймовых проектах векторы переводятся в единицы проекта автоматически; диаметр в мастере всегда вводится в мм.

Используйте тёмные обработанные области на светлом фоне, при необходимости с заливкой. Перед изготовлением партии проверьте код телефоном на пробном образце. Скругление углов фрезой, контраст и покрытие влияют на считывание.

#Обновления

Номер версии виден в заголовке. При запуске проверяется последний стабильный публичный релиз GitHub. При наличии новой версии показываются её номер и кнопка «Обновить», открывающая страницу релиза. Скачайте новый .vgadget и установите через Install New Gadget…. Автоматической замены файлов нет.

Без интернета генератор QR работает. Проверка обновлений ограничена по времени и при ошибке сети не блокирует создание векторов. Ссылка для QR не отправляется на сервер; она обрабатывается локально. Для проверки версии запрашивается только публичная информация о релизе.

#Сборка и тесты

powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt -r requirements-test.txt
.venv\Scripts\python -m unittest discover -s . -p test_qr.py -v
.venv\Scripts\python -m PyInstaller --noconfirm --onefile --noconsole --name QRMasterEngine --distpath bin --workpath build/qr qr_engine.py
.venv\Scripts\python -m unittest discover -s . -p test_qr.py -v
.venv\Scripts\python package_qr.py


Среда сборки: Python 3.11 x64, Windows. Готовый пакет: QRMaster_Aspire_1.1.0.vgadget.

Тесты проверяют декодирование геометрии и модели кармана фрезами 2/4/6 мм через независимый ZXing, кириллицу в ссылках, защитное поле, замкнутость контуров, автоматический размер, преобразование мм/дюймов, закрытие мастера при успехе, повторный ввод после ошибки и сравнение версий обновлений.

#Сторонние компоненты

QR формируется библиотекой [Segno](https://segno.readthedocs.io/), соседние квадраты объединяются Shapely/GEOS. Лицензии сторонних компонентов находятся в папке LICENSES установочного пакета. Vectric Aspire в поставку не входит.

Папки локальной среды, сборки, временные проверки и пользовательские проекты не включаются в репозиторий.
